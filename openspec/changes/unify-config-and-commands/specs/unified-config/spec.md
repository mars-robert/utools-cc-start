## ADDED Requirements

### Requirement: 单一配置入口

系统 SHALL 提供一个统一配置中心功能（关键词如 `cconf` / `ccstartconf` / `配置`），作为启动配置、快捷命令管理与终端设置的唯一入口。系统 SHALL NOT 为命令管理保留独立的功能入口。

#### Scenario: 打开统一配置中心
- **WHEN** 用户触发配置关键词
- **THEN** 系统打开统一配置中心，默认展示「启动配置」标签页

#### Scenario: 命令管理无独立入口
- **WHEN** 用户希望管理快捷命令
- **THEN** 用户通过统一配置中心的「快捷命令」标签页进入，而非独立的管理命令关键词

### Requirement: 标签页式分区导航

统一配置中心 SHALL 以标签页形式划分为「启动配置」「快捷命令」「终端设置」三个分区，并允许用户在分区间切换。

#### Scenario: 在分区间切换
- **WHEN** 用户点击某个标签页
- **THEN** 系统显示该分区内容，其他分区隐藏，且当前选中标签页有视觉高亮

#### Scenario: 分区内容独立保存
- **WHEN** 用户在某个分区修改配置并保存
- **THEN** 该分区的修改被持久化，切换到其他分区不会丢失已保存的修改
