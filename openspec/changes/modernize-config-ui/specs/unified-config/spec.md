## MODIFIED Requirements

### Requirement: 标签页式分区导航

统一配置中心 SHALL 采用左右分栏布局，左侧为固定宽度的导航栏（图标 + 文字），右侧为可滚动的内容区。用户点击左侧导航项切换右侧内容。

#### Scenario: 左右分栏布局
- **WHEN** 用户打开统一配置中心
- **THEN** 左侧显示固定宽度的导航栏，包含「启动配置」（图标 📦）与「快捷命令」（图标 ⚡）；右侧显示当前选中分区的内容，内容区可独立滚动

#### Scenario: 在分区间切换
- **WHEN** 用户点击左侧某个导航项
- **THEN** 该导航项高亮，右侧内容区切换到对应分区，其他分区隐藏

#### Scenario: 分区内容独立保存
- **WHEN** 用户在某个分区修改配置并保存
- **THEN** 该分区的修改被持久化，切换到其他分区不会丢失已保存的修改

## ADDED Requirements

### Requirement: 启动命令单选列表

系统 SHALL 以单选列表（radio buttons）形式展示所有启动命令选项，用户点击即选中，无需下拉展开。

#### Scenario: 显示所有启动命令选项
- **WHEN** 用户进入「启动配置」分区
- **THEN** 所有启动命令（内置预设 + 用户自定义）以单选列表形式展示，当前选中项的 radio 被选中

#### Scenario: 点击选中
- **WHEN** 用户点击某个启动命令的 radio 或其标签
- **THEN** 该选项被选中并立即保存，其他选项的 radio 变为未选中状态

#### Scenario: 管理启动命令
- **WHEN** 用户点击启动命令列表下方的「+ 新增」或某个自定义项旁的「编辑」按钮
- **THEN** 打开管理弹窗，允许增删改自定义项；内置预设不可删除

### Requirement: 终端单选列表与路径可编辑

系统 SHALL 以单选列表（radio buttons）形式展示所有终端选项，并为每个终端项（含预设）显示可编辑的路径输入框。预设终端的路径输入框默认填充系统探测到的路径，用户可修改后保存。

#### Scenario: 显示所有终端选项及路径
- **WHEN** 用户进入「启动配置」分区
- **THEN** 所有终端（预设 + 自定义）以单选列表形式展示，每个终端项旁显示一个路径输入框；预设终端的输入框默认填入探测到的路径（如 PowerShell → `C:\Windows\System32\...\powershell.exe`），用户可修改

#### Scenario: 修改预设终端路径
- **WHEN** 用户在某个预设终端（如 PowerShell）的路径输入框中修改路径并保存
- **THEN** 该预设项的路径被覆盖保存，后续启动时使用用户指定的路径而非系统探测路径

#### Scenario: 恢复预设路径
- **WHEN** 用户点击预设终端的「恢复默认」按钮
- **THEN** 该预设项的自定义路径被清除，路径输入框恢复为系统探测到的默认值

#### Scenario: 非 Windows 平台隐藏终端
- **WHEN** 用户在 macOS 或 Linux 上打开统一配置中心
- **THEN** 终端列表不显示

### Requirement: 卡片式视觉风格

系统 SHALL 采用卡片式设计风格，包括圆角、阴影、明确的视觉分组与合理留白，支持亮色与暗色主题。

#### Scenario: 卡片容器
- **WHEN** 显示启动命令列表或终端列表
- **THEN** 每个选项组以卡片形式呈现：白色背景（暗色主题为深灰）、圆角 8-12px、轻阴影、内边距 16-20px

#### Scenario: 按钮与交互状态
- **WHEN** 用户 hover 或点击按钮、radio、列表项
- **THEN** 显示明确的视觉反馈：hover 时背景色微调、圆角按钮、主色调强调

#### Scenario: 暗色主题适配
- **WHEN** 系统处于暗色模式
- **THEN** 背景、文字、边框、阴影颜色自动切换为暗色主题配色
